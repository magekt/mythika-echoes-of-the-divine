## Existing Cross-System Pattern (from journey.js choose path)

EncounterSystem.choose() currently routes rewards through:
- Economy.addGold / Economy.addKarma / Economy.addDivineFragments
- Progression.addPartyXP
- CultivationSystem.addPrana / CultivationSystem.addCultivationBase
- CultivationSystem.equipAura (for aura grants)
- Economy.addItem (which internally calls QuestSystem.trackCollect for items)
- AchievementSystem.check() — called at end of choose()

Gap: No QuestSystem.trackEncounter() call — encounter completions are invisible to quests.
Gap: No encounter-related achievement — encounter completions are invisible to achievements.

## QuestSystem API Surface

```js
// Existing tracking methods (src/systems/quest.js):
QuestSystem.trackKill(enemyId, zoneId, isBoss)      // combat kills
QuestSystem.trackFish()                                // fishing catches
QuestSystem.trackCollect(itemName, qty)                // item collection
QuestSystem.trackExplore(zoneId, amount)               // zone exploration ticks
QuestSystem.trackForge(slotId)                         // forge upgrades
QuestSystem.trackRealm(realmId)                        // realm breakthroughs
```

New method to add: `QuestSystem.trackEncounter(encounterId)` — mirrors the pattern of the above methods (pure read, iterate quests, increment matching type, notify on completion).
