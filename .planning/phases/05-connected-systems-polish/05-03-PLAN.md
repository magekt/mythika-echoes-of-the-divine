## Performance Pattern (from game.js)

The game uses `?probe` URL param for FPS logging. The existing probe pattern:
- `G._probe = /[?&]probe/.test(location.search)` — activated by URL param
- Every 5 seconds: `console.log('[Mythika] fps=' + ...)` — logs rolling FPS
- Adaptive Reduce Motion: two consecutive sub-30fps windows auto-enable reduceMotion
- Memory: 30-min session memory check is manual (no automated memory profiling)

## Scene Leave Pattern (from codebase audit)

Every scene has a `leave()` method that cleans up:
- `this.data.buttons = []` — releases MagneticBtn references
- `this.data.scrollY = 0` — resets scroll state
- Scene-specific cleanup (timers, enemies, logs, etc.)

CombatScene.leave() additionally: `clearCombatTimers()`, clears enemies/heroes arrays, stops music.
EncounterScene.leave() clears: buttons, staticDraws, result, encounterId, resolved flag.
ZoneExploration.leave() clears: buttons, log, zone reference, enemy/loot state.
