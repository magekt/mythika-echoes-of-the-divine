**Step 2: Add MagneticBtn reduced-motion guard in `src/ui/button.js`**

In `UI.MagneticBtn` (line 375), the `baseBtn.update` function (line 388) currently runs the spring.scale animation unconditionally:
```javascript
// Line 394 (current):
```

Add a reduced-motion guard so the scale spring snaps to target immediately when reduced-motion is active:
```javascript
const reduceMotion = R.reducedMotion ? R.reducedMotion() : false;
if (reduceMotion) {
  spring.scale = spring.targetScale;
} else {
  spring.scale += (spring.targetScale - spring.scale) * Math.min(1, dt * stiffness / damping);
  if (Math.abs(spring.scale - spring.targetScale) < 0.001) spring.scale = spring.targetScale;
}
this._springScale = spring.scale;
```

Note: `reduceMotion` is already declared later in the update function (line 399) for icon spring. Move the declaration to the top of the update function so it's available for both the scale spring and icon spring checks.

**Step 3: Add Fade reduced-motion guard in `src/engine/game.js`**

In `Fade.update` (line 125), add a reduced-motion check so the fade completes instantly instead of animating:
```javascript
update: function(dt) {
  if (this.alpha !== this.target) {
    const reduceMotion = R.reducedMotion ? R.reducedMotion() : false;
    if (reduceMotion) {
      this.alpha = this.target;
    } else {
      const dir = this.target > this.alpha ? 1 : -1;
      this.alpha += dir * this.speed * dt;
      if ((dir > 0 && this.alpha >= this.target) || (dir < 0 && this.alpha <= this.target)) {
        this.alpha = this.target;
      }
    }
    // Scene transition logic (runs when alpha reaches target)
    if (this.alpha === this.target && this.pendingScene) {
      const pending = this.pendingScene;
      const name = typeof pending === 'string' ? pending : pending.name;
      const enterOptions = typeof pending === 'string' ? undefined : pending.enterOptions;
      this.pendingScene = null;
      Input.clear();
      UI.Modal.clearAll();
      if (G.currentScene && G.currentScene.leave) G.currentScene.leave();
      G.currentScene = G.scenes[name];
      G.state.scene = name;
      safeEnter(G.currentScene, enterOptions);
      this.target = 0;
      this.speed = 4;
    }
  }
},
```

This restructuring pulls the scene-transition logic out of the `else` branch and makes it a shared follow-up check, so it works for both the normal animated path and the instant reduced-motion path.
