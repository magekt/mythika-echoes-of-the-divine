In `src/scenes/travelMap.js`:

1. **Add viewport intersection helper** (new method on the scene object, near getRegionRect):
   ```javascript
   _intersectsViewport: function(rect, viewport) {
     return rect.x + rect.w > viewport.x && rect.x < viewport.x + viewport.w &&
            rect.y + rect.h > viewport.y && rect.y < viewport.y + viewport.h;
   },
   ```

2. **Cull regions in `renderMap`** (line 400). The loop `for (const entry of MapLayout.ENTRIES) this.renderRegion(ctx, entry)` should skip off-screen entries:
   ```javascript
   for (const entry of MapLayout.ENTRIES) {
     const rect = this.data._cachedRects.get(entry.zoneId);
     if (rect && !this._intersectsViewport(rect, viewport)) continue;
     this.renderRegion(ctx, entry);
   }
   ```

3. **Cull connections in `renderConnections`** (line 423). For each connection, check if BOTH endpoints are off-screen before skipping:
   ```javascript
   renderConnections: function(ctx) {
     const viewport = this.data._cachedMetrics ? this.data._cachedMetrics.viewport : this.getMapViewport();
     ctx.save();
     ctx.strokeStyle = R.colors.borderFocus;
     ctx.lineWidth = 2;
     ctx.setLineDash([5, 6]);
     for (const entry of MapLayout.ENTRIES) {
       const from = this.getRegionRect(entry);
       if (!this._intersectsViewport(from, viewport)) continue;
       for (const targetId of entry.connections || []) {
         const target = MapLayout.getEntry(targetId);
         if (!target) continue;
         const to = this.getRegionRect(target);
         if (!this._intersectsViewport(to, viewport)) continue;
         ctx.beginPath();
         ctx.moveTo(from.x + from.w / 2, from.y + from.h);
         ctx.lineTo(to.x + to.w / 2, to.y);
         ctx.stroke();
       }
     }
     ctx.restore();
   },
   ```

4. **Cull the grid background in `renderMapTexture`** (line 404). The grid currently draws across the entire viewport. When the map is panned so some regions are off-screen, the grid should still draw (it's a background pattern, not content). Leave grid rendering as-is — it fills the viewport regardless of content position and is cheap (simple stroke calls).
