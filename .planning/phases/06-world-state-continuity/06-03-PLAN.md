# Root cause reference
The service worker sw.js uses cache-first for all JS assets. Phase 6 deployed new world_state.js and updated save.js/game.js but did NOT bump the cache key (remained mythika-v9) and did NOT add world_state.js to ASSETS. Result: stale worker serves old JS, new index.html loads but old save.js has no WorldState reference → G.state.world stays undefined.
</context>
