Overlay-flag contract (2 engine lines each, zero scene changes):
```javascript
// src/engine/game.js — inside Notify.render(ctx), around the draw loops:
if (typeof window !== 'undefined' && window.__layoutHarness) window.__layoutHarness.overlay = true;
try { /* existing toast + achievement draw code, UNCHANGED */ }
finally { if (typeof window !== 'undefined' && window.__layoutHarness) window.__layoutHarness.overlay = false; }
// src/ui/modal.js — inside UI.Modal.render(ctx), around ghost + active _paint calls: same shape.
```
The `finally` is load-bearing (a throw mid-render must not exempt later draws);
the injector's frame-end `selfCheck()` proves the flag is false. Both guards must
be typeof-guarded so normal play (no harness global) is byte-identical behavior.

verify_matrix.py conventions to preserve: stdlib only, `serve()` loopback HTTP,
`find_chrome()` + `RUNNER_FLAGS`, `PROFILES`, `--budget/--outdir/--fps` flags,
`tools/shots/` evidence dir, exit 1 on any failure. EXTEND in place — do not fork.
