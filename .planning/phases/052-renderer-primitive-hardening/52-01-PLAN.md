Add R.easePremiumInv function AFTER R.easePremium (after line 187) per D-03 (CONTEXT.md decision C):

R.easePremium uses smoothstep: `t * t * (3 - 2 * t)` which is a cubic polynomial: `3t² - 2t³`

The analytical inverse requires solving `3t² - 2t³ = p` for `t`. This is a cubic equation. Use binary search for simplicity and guaranteed accuracy:

```javascript
R.easePremiumInv = function(p) {
  if (typeof p !== 'number' || Number.isNaN(p)) p = 0;
  p = Math.max(0, Math.min(1, p));
  if (p === 0) return 0;
  if (p === 1) return 1;
  // Binary search for t where easePremium(t) = p
  var lo = 0, hi = 1;
  for (var i = 0; i < 20; i++) {
    var mid = (lo + hi) / 2;
    var val = mid * mid * (3 - 2 * mid);
    if (val < p) lo = mid; else hi = mid;
  }
  return (lo + hi) / 2;
};
```

20 iterations gives ~1e-6 precision, well within 0.001 requirement.

R.reducedMotion.watch = function(cb) {
  if (typeof cb !== 'function') return function() {};
  var listeners = R.reducedMotion._listeners || (R.reducedMotion._listeners = []);
  listeners.push(cb);
  // Lazy-attach matchMedia listener on first watch
  if (!R.reducedMotion._mediaQuery && typeof window !== 'undefined' && window.matchMedia) {
    try {
      var mq = window.matchMedia('(prefers-reduced-motion: reduce)');
