# Plan 38-02: 20 Enemy Portrait Icons (ART-02)

## Objective
Add a 60x60 procedural portrait icon for the 20 highest-frequency enemies. The portrait is a distinct head shape filled with a dark tint, gold rim light, and a silhouette of the shoulders/neck. Shown alongside the enemy name in combat and exploration cards.

## Top-20 Enemies (by ZONE_ENEMIES encounter frequency)
aryavarta (6): bandit, wolf, giantSpider, rakshasa, wildBoar, snake
dandaka (6): wraith, darkElf, shadowMage, treant, naga, (giantSpider already counted)
meru (4 new): asuraWarrior, orc, iceElemental, fireElemental
patala (2 new): asura, hellHound
svarga (1 new): indra
= 20 total

## Tasks

### Task 1: Create `src/systems/enemyPortraits.js`
- `EnemyPortrait.render(ctx, x, y, w, h, enemyId)` — draws the 60x60 silhouette
- Offscreen cache: `EnemyPortrait._cache = {}` keyed by enemyId, LRU max 20
- Each enemy type has a distinct `drawFn(ctx)` that draws into the 60x60 local canvas
- Falls back to `drawGeneric(ctx)` for unlisted enemies: dark circle + shoulders
- `R.colors.gold` for rim light; `R.colors.textDark` for body fill; `R.colors.textDim` for shadow

### Task 2: Wire into `combatScene.js` enemy card
- Find where enemy name is drawn in the combat HUD (combatScene.js ~line 110-140)
- Draw `EnemyPortrait.render(ctx, cardX + 4, cardY + 4, 52, 52, enemy.id)` before the name text
- Shift name text x by 60px to accommodate the portrait

### Task 3: Wire into `zoneExploration.js` encounter card
- Same as Task 2 but for the exploration encounter card (encCard.render in zoneExploration.js ~line 116)
- Portrait at 44x44 for the smaller card

### Task 4: Register in `index.html` + `sw.js`
- Add `<script src="src/systems/enemyPortraits.js"></script>` after `zoneArt.js`
- Add to `sw.js` ASSETS
