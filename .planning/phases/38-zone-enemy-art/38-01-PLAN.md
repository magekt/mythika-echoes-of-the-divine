# Plan 38-01: 8 Zone Backdrops (ART-01)

## Objective
Replace the current flat `bgColor` linear gradients in zone exploration with distinct 3-layer procedural backdrops: gradient sky, mid-ground silhouette (unique per zone), and accent particles. All 8 zones in `ZONES` get a unique visual.

## Context
- `src/data/zones.js` — 8 zone IDs: `aryavarta, dandaka, meru, patala, svarga, tapobhumi` + check for 2 more
- `src/engine/backgrounds.js:31` — `fallbackGenerators.zone` currently does flat linear gradient; `registerSlot('zone:'+id)` caches the result
- `src/scenes/zoneExploration.js:55` calls `R.Backgrounds.registerSlot('zone:' + zoneId)` in enter()
- `src/scenes/combatScene.js:104` same
- No external asset files allowed — everything canvas-drawn

## Zone Visual Palettes

| Zone | Sky Gradient | Silhouette | Accent |
|---|---|---|---|
| aryavarta | `#0a1a20 → #1a2a30` | Rolling hills + sparse tree | Golden sun disc |
| dandaka | `#0a0a1a → #1a0a2a` | Dense pine treeline | Purple mist bands |
| meru | `#1a1a3a → #0a1a3a` | Jagged mountain peak | Teal aurora streak |
| patala | `#1a0505 → #2a0808` | Serpent-wreathed pillars | Orange ember particles |
| svarga | `#1a2a4a → #2a4a6a` | Cloud columns + lotus | White light rays |
| tapobhumi | `#1a1508 → #2a2010` | Sand dunes + bare trees | Ochre dust motes |

## Tasks

### Task 1: Create `src/systems/zoneArt.js`
- `ZoneArt.paint(ctx, zoneId, w, h)` — paints onto the offscreen canvas (400x720) for the given zone
- For each zone: 3 layers (sky gradient → silhouette → accent), all using `ctx.createLinearGradient` + `ctx.fillRect`/`ctx.beginPath`
- Zone-specific hex values allowed only in this file; no hex in scene files
- Export `ZoneArt.paintZone(zoneId, offCanvas)` that the backgrounds.js LRU can call

### Task 2: Update `src/engine/backgrounds.js`
- In `fallbackGenerators.zone`, replace the flat `bgColor` gradient with a call to `ZoneArt.paintZone(zoneId, offCanvas)` when available
- Keep the flat `bgColor` gradient as fallback if `ZoneArt` is undefined (pre-boot guard)

### Task 3: Register in `index.html` + `sw.js`
- Add `<script src="src/systems/zoneArt.js"></script>` after `zone_rewards.js` in systems block
- Add `'src/systems/zoneArt.js'` to `sw.js` ASSETS
