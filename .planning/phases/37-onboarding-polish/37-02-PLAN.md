# Phase 37 Plan 02: Stat Gloss Inline System (ONB-02)

## Objective
When a first-time player views class cards in character creation (step 0), each stat abbreviation gets a 1-line gloss the first time it appears. Subsequent views suppress the glosses. No modals, no tooltips — just small `R.fonts.xs` text inline below each stat label in the class card.

## Grey-Area Decision (auto-answered)
**Auto:** Glosses appear on ALL stat labels (STR, AGI, MAG, DEF, HP, MP, CRT) in the step-0 class cards, not just the ones the player selected. Suppression is per-stat: `G.state.glossSeen.STR = true` after first view. Class cards in step 0 are the trigger surface — the hero step (step 1) shows the same stats but without glosses by then (player already saw them in step 0).

## Context
- `src/scenes/characterCreate.js:buildClassButtons()` (line ~123) builds step-0 class cards
- Each class card shows bonus lines like `"STR+2 AGI+1"` — these are where glosses attach
- `R.fonts.xs` exists for small text
- `G.state.glossSeen = {}` — per-stat key, set true after first display
- Gloss map (hardcoded in tour.js or a new gloss.js):
  - STR: "Strength — raises melee attack damage"
  - AGI: "Agility — faster turn order, more dodge"
  - MAG: "Magic — raises spell damage and max MP"
  - DEF: "Defense — reduces all incoming damage"
  - HP: "Health — total hit points"
  - MP: "Mana — fuel for skills and spells"
  - CRT: "Critical — chance of a double-damage hit"

## Tasks

### Task 1: Create `src/systems/gloss.js`
```js
const GLOSS_MAP = {
  STR: 'Strength — melee attack power',
  AGI: 'Agility — faster turns, more dodge',
  MAG: 'Magic — spell power and max MP',
  DEF: 'Defense — reduces incoming damage',
  HP:  'Health — total hit points',
  MP:  'Mana — fuel for skills',
  CRT: 'Critical — chance of double damage'
};

const GlossSystem = {
  gloss: function(label) { return GLOSS_MAP[label] || null; },
  shouldShow: function(label) {
    return GLOSS_MAP[label] && !(G.state.glossSeen && G.state.glossSeen[label]);
  },
  markSeen: function() {
    G.state.glossSeen = G.state.glossSeen || {};
    for (const k of Object.keys(GLOSS_MAP)) G.state.glossSeen[k] = true;
  }
};
```

### Task 2: Register in `src/engine/game.js`
- Add `window.GlossSystem = GlossSystem` alongside other system globals
- Add `<script src="src/systems/gloss.js"></script>` to `index.html` systems block, after `tour.js`

### Task 3: Wire into `characterCreate.js`
- In `buildClassButtons()`, after the bonus parts line is drawn, check each stat label: if `GlossSystem.shouldShow(label)` is true, draw the gloss below in `R.fonts.xs` at `R.colors.textDim`
- Call `GlossSystem.markSeen()` at the end of `buildClassButtons()` so the glosses only show on this first render
- For the stat bonus display at `characterCreate.js:212` (hero stats line) — also add glosses here for stats not yet seen

### Task 4: Save-state hydration
- `G.state.glossSeen = G.state.glossSeen || {}` in save.js or state initialization
