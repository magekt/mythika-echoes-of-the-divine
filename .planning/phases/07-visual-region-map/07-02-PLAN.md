## Scene factory pattern (from scenes/codemap.md)
```js
const scene = Scene.create({
  name: 'sceneName',
  data: { /* mutable scene state */ },
  enter: function() { /* build UI, set up data */ },
  leave: function() { /* clean up */ },
  update: function(dt) { /* input + tick */ },
  render: function(ctx) { /* draw every frame */ }
});
```

## Scene transitions (from scene-helpers)
- `gScene.push('sceneName')` — navigate to new scene
- `gScene.pop()` — return to previous scene
- Navigation from ashram: `gScene.push('travelMap')`
- Enter zone: `gScene.push('zoneExploration')` with `G.state.currentZone = zoneId`

## Key globals available
- `G` — global state, canvas dimensions (`G.W`, `G.H`), `G.CONTENT_TOP`
- `R` — renderer: `R.colors.*`, `R.fonts.*`, `R.radius.*`, `R.roundRect()`, `R.textCenter()`
- `Input` — touch state: `Input.startX`, `Input.startY`, `Input.x`, `Input.y`, `Input.down`, `Input.isMouse`
- `ZONES` — zone data keyed by zoneId
- `ZoneAccess` — `ZoneAccess.status(zoneId)` → {allowed, percentage, complete}
- `WorldState` — `WorldState.getRegion(zoneId)` → {value, control} | null
- `UI.MagneticBtn`, `UI.Button`, `UI.ProgressBar`, `UI.PremiumShell`, `UI.EmptyState` — available UI components
- `UI.Modal.active` — modal guard pattern (must be checked in update)
- `Hints.show(scene, msg)` — one-time hint toast

## Interaction model
- Touch drag on map area → pan the viewport (dx, dy applied to mapX, mapY)
- Tap on zone card (no significant drag) → select zone, show detail panel
- Tap on selected zone again → same behavior as first tap
- Tap on empty space / back button → deselect / close detail panel
- "Enter Zone" button → `gScene.push('zoneExploration')` (same as before)
- "Close" button → deselect zone, return to map view

### Design

**Scene.data shape:**
```js
data: {
  buttons: [],           // MagneticBtn instances for back, enter, close
  selectedZone: null,    // zoneId string or null
  scrollY: 0,            // RETAINED for scene-helpers compat — set to 0 always
  contentHeight: 0,      // RETAINED for scene-helpers compat — set to 0 always
  // Pan state
  mapX: 0,               // pan offset X in canvas px
  mapY: 0,               // pan offset Y in canvas px
  // Drag detection
  isDragging: false,
  startX: 0,
  startY: 0,
  startMapX: 0,
  startMapY: 0,
  didDrag: false,        // true if drag exceeded TAP_THRESHOLD
}
```

**Constants (top of file, before Scene.create):**
```js
const TAP_THRESHOLD = 15;       // px — drag < this = tap
const GRID_SIZE = 100;          // virtual map grid
const GRID_PADDING = 8;         // virtual grid units padding
const REGION_H = 20;            // virtual grid height per zone
```

**Coordinate transform (helper):**
```js
// Virtual 0–100 grid → canvas pixel coords
// Scale = (canvasWidth - 2*PADDING) / GRID_SIZE
// Each zone at (x, y) in MapLayout maps to:
//   px = PADDING + x * scale + mapX
//   py = PADDING + y * scale + mapY
//   pw = w * scale
//   ph = h * scale
```

**enter():**
- Call `Hints.show('map', 'Tap a region to inspect it. Drag to pan.')`
- Set `this.data.selectedZone = null; this.data.mapX = 0; this.data.mapY = 0`
- Build 3 buttons using `UI.MagneticBtn`:
  - `backBtn`: top-left, label "← Back", variant 'ghost', onClick → `gScene.pop()`
  - `enterBtn`: bottom-center, label "Enter Zone", variant 'primary', initially hidden (visible only when a zone is selected and unlocked)
  - `closeBtn`: top-right of detail panel area, label "✕", variant 'ghost', initially hidden

**leave():**
- Reset all data fields to defaults.

**update(dt):**
- Follow the standard modal guard: `if (UI.Modal.active) { UI.Modal.handleInput(); return; }`
- Update all MagneticBtn instances: `UI.updateButtons(this.data.buttons, dt)`
- Handle button clicks via `UI.handleButtons(this.data.buttons)` — if a button's onClick fires, `return` after handling.
- **Pan/tap handling (only if no modal active):**
  ```
  if (Input.down && !this.data.isDragging) {
    // Touch/mouse started
    this.data.isDragging = true;
    this.data.didDrag = false;
    this.data.startX = Input.x;
    this.data.startY = Input.y;
    this.data.startMapX = this.data.mapX;
    this.data.startMapY = this.data.mapY;
  }
  if (this.data.isDragging && Input.down) {
    const dx = Input.x - this.data.startX;
    const dy = Input.y - this.data.startY;
    if (Math.abs(dx) > TAP_THRESHOLD || Math.abs(dy) > TAP_THRESHOLD) {
      this.data.didDrag = true;
      this.data.mapX = this.data.startMapX + dx;
      this.data.mapY = this.data.startMapY + dy;
    }
  }
  if (this.data.isDragging && !Input.down) {
    // Touch ended
    if (!this.data.didDrag) {
      // This was a tap — check zone hit
      this.handleTap(Input.x, Input.y);
    }
    this.data.isDragging = false;
  }
  ```
- Keep `this.data.scrollY = 0` always (scene-helpers compat).

**handleTap(tapX, tapY):**
- Iterate `MapLayout.ENTRIES` in reverse (top-drawn zones first for hit priority).
- For each entry, compute canvas coordinates using the coordinate transform.
- If `(tapX, tapY)` is inside the rect → set `this.data.selectedZone = entry.zoneId; return;`
- If no hit → `this.data.selectedZone = null`

**render(ctx):**
- Standard flow:
  ```
  ctx.clearRect(0, 0, G.W, G.H)
  R.roundRect(ctx, 0, 0, G.W, G.H, 0, R.colors.bg)  // background
  ```
- **Draw title bar:**
  ```
  R.textCenter(ctx, 'World Map', G.W / 2, G.CONTENT_TOP + 10, R.colors.text, R.fonts.md)
  ```
- **Draw connections** (lines between zones):
  - For each entry in `MapLayout.ENTRIES`, for each connected zoneId:
    - Compute center of this entry, center of the connected entry (canvas coords)
    - If both zones are unlocked (MapHelpers.getStatus !== 'locked') → draw line in a muted connector color
    - If any is locked → draw dashed line or skip (prefer skip for clean look)
    - Line color: `R.colors.muted` or derive from realm color at 40% alpha
    - Line width: 2px
- **Draw each region node:**
  For each entry in `MapLayout.ENTRIES`:
    - Compute canvas position from the coordinate transform
    - Status = `MapHelpers.getStatus(entry.zoneId)`
    - Color = `MapHelpers.getStatusColor(status)`
    - Fill the region rect with a low-alpha version of the color
    - Draw border (2px) in the status color
    - **If LOCKED:** draw with 40% opacity, add a small lock icon (Unicode 🔒) or text overlay
    - **If COMPLETED:** draw with a subtle golden overlay and a ✓ badge
    - Draw zone name centered in the region: `R.textCenter(ctx, entry.name, cx, cy - 4, entry.textColor || R.colors.text, R.fonts.sm)`
    - Draw realm label below name: `R.textCenter(ctx, entry.realm, cx, cy + 8, R.colors.muted, R.fonts.xs)`
    - **If hasInfluence:** draw a small colored dot or badge (per WorldState.getControlState)
    - **If selected:** draw selection highlight (glowing border or thicker border in gold)
- **Draw back button:** `UI.updateButtons([this.data.backBtn], 0); UI.renderButtons(ctx, [this.data.backBtn])` (or the appropriate render call — follow existing pattern in other scenes).
- **If a zone is selected — draw detail panel:**
  - Panel is a fixed rect at the bottom of the viewport, height ~120px, full width
  - Background: `R.colors.panel` with `R.roundRect`
  - Content:
    - Zone name (bold, R.fonts.md)
    - Status text + color (e.g., "Active — 45%" or "Locked — Requires: Aryavarta (100%)")
    - Level range: "Lv. 1–9"
    - Realm label
    - Completion bar using `UI.ProgressBar` if percentage > 0
    - Two buttons: "Enter Zone" (MagneticBtn primary) if unlocked, and "Close" (MagneticBtn ghost)
  - Panel slides in from bottom when selectedZone is set (or just appears — keep simple first pass)

### Anti-patterns to avoid
- Do NOT use `this.data.scrollY` for the new pan navigation — set it to 0 and keep for compat only.
- Do NOT use `gScene.goto()` — use `gScene.push()` for forward navigation, `gScene.pop()` for back.
- Do NOT read `Input.startX/startY` during drag — use `Input.x/y` and the stored start values.
- Do NOT render beyond the canvas bounds — clamp zone rects to the visible area or let pan move them off-screen (pan is the mechanism to reach off-screen zones).
- Do NOT add zone IDs not in MapLayout.ENTRIES.
- Do NOT hardcode zone positions — always read from MapLayout.ENTRIES.
