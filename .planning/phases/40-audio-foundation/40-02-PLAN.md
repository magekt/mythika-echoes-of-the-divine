# Plan 40-02: Audio Toggle Persistence

## localStorage Schema
Key: `mythika_audio`
```json
{ "mute": false, "musicOn": true, "sfxOn": true }
```

## Autoplay Gate
`initAudio()` sets up listeners for `pointerdown`, `touchend`, `keydown`.
`Audio.unlock()` creates `AudioContext` on first gesture. No changes.

## Toggle Independence
- Music toggle: sets `musicOn`, calls `stopMusic()` or `playMusic()` — no SFX effect
- SFX toggle: sets `sfxOn`, no music effect
- Mute: sets `mute=true` + forces both off; unmute restores prior values
