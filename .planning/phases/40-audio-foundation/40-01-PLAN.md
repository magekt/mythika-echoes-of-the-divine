# Plan 40-01: UI SFX + Audio Toggles + localStorage Persistence

## Changes

### src/engine/audio.js
- Added `mute`, `_ambientNodes`, `_ambientInterval`, `_ambientChordIndex`, `_delayNode/Feedback/Dry/Wet` properties
- `Audio.loadPrefs()`: reads `mythika_audio` from localStorage on boot
- `Audio.savePrefs()`: writes mute/musicOn/sfxOn to localStorage
- `Audio.toggleMute()`: master mute flips both musicOn and sfxOn off; restores on unmute
- `Audio.toggleMusic()`, `Audio.toggleSFX()`: individual channel toggles with persistence
- `Audio.beep()`: now checks `Audio.mute` in addition to `Audio.sfxOn`
- `Audio.playMusic()`: now checks `Audio.mute`
- `Audio.stopAll()`: stops both melodic and ambient tracks
- `Audio.cleanup()`: calls `stopAll()` instead of just `stopMusic()`
- UI SFX `toast()`, `modalOpen()`, `btnTap()`: now check `Audio.mute`

### src/engine/game.js
- Calls `Audio.loadPrefs()` after `initAudio()` at boot

### src/scenes/settings.js
- Audio section now has three toggles: Mute, SFX, Music
- Mute toggle calls `Audio.toggleMute()`; SFX/Music call `Audio.toggleSFX()`/`Audio.toggleMusic()`
- When Mute is ON, SFX/Music buttons are disabled
- All three use `Audio.btnTap()` SFX on click

### src/ui/modal.js
- `UI.Modal.show()` calls `Audio.modalOpen()` on dialog open

## SFX Wiring
| SFX | Trigger |
|-----|---------|
| `Audio.toast()` | `Notify.show()` (game.js) |
| `Audio.modalOpen()` | `UI.Modal.show()` (modal.js) |
| `Audio.btnTap()` | Settings toggle buttons (settings.js) |

## Gain Node Topology
```
ctx.destination ← SFX (direct oscillator→gain→destination)
ctx.destination ← _musicGain ← melodic oscillators
ctx.destination ← _musicGain ← ambient oscillators → filter → delay → destination
```
