Wire qualifying gameplay actions into the Influence system so the map can display shifting
regional control driven by canonical player actions.

journey completions all shift influence. This plan attaches the four hooks with idempotent
guards via WorldState transitions.
Output: Influence applied at zone_rewards, encounter, combat, and journey endpoints.
</objective>
