## Tech Debt → v10

1. `UI.EmptyState`/`UI.HeroMoment` per-frame allocation pattern: EmptyState (button.js:812-816) still constructs `UI.MagneticBtn` inside `render` on every call unless caller pre-builds — REV-04 fully landed in HeroMoment; EmptyState CTA remains construct-on-each-call. Candidate for v10 construct-once migration.
2. `ctx.filter = blur(...)` in `Scene.entranceReveal.render` (scene-helpers.js:222) — canvas filter is expensive on low-end mobile; consider a cheaper 2-frame sample-blur or gated by `R.probe.perfTier` in a perf pass.
3. `MagneticBtn` icon springs use ad-hoc lerp constants (`dt*8`, `stiffness 120/22` in button.js:419-420) instead of the shared `R.spring` for position — inconsistent with press-spring path; unify for v10 motion-system work.
4. `R.easePremium` is a smoothstep approximation of the bezier, not exact cubic-bezier evaluation (renderer.js:182 comment). Visually acceptable; document the approximation or swap to real bezier solver if pixel-exact curves matter.
