## v10.0 Requirements

### UI Component Factory (Foundation Layer)

- [x] **COMP-01**: `UI.Component(x, y, w, h, opts)` base factory returns `{ x, y, w, h, render(ctx), update(dt), contains(px, py), onClick: null, data: null }` — base object shared by all UI components
- [x] **COMP-02**: `UI.mixinRender(component, drawFn)` mixin adds `render(ctx)` that calls `drawFn(ctx, component)`; used by `UI.Button`, `UI.Panel`, `UI.Modal`, `UI.List`, `UI.Feedback`, `UI.HeroSurface`, `UI.TabBar`, `UI.Input`, `UI.Dialog`, `UI.EmptyState`, `Scene.HeroMoment`
- [x] **COMP-03**: `UI.mixinUpdate(component)` mixin adds `update(dt)` that calls `component._updateHook?.(dt)`; used by components needing per-frame logic (buttons, panels, modals, lists, scene CTAs)
- [x] **COMP-04**: `UI.mixinSpring(component, config)` mixin adds `_springState` + `_springStep = R.spring(config)`; `update(dt)` advances spring and stores result in `component._springValue`
- [x] **COMP-05**: `UI.mixinEase(component)` mixin adds `easedValue(t)` using `R.easePremium(t)` for entrance/exit transitions
- [x] **COMP-06**: `UI.mixinContains(component)` mixin adds `contains(px, py)` using `R.radius` scale for hit-testing
- [x] **COMP-06b**: All existing UI factories refactored to compose from `UI.Component` + mixins instead of hand-rolled objects
- [x] **COMP-07**: No per-frame object allocation in any component `render()` or `update()` — all state allocated once at construction, mutated in place

### Spring Config Registry

- [x] **SPR-01**: `R.springConfigs` object exists with named configs for all spring use-cases
- [x] **SPR-02**: `R.springConfig(name)` returns config by name; callers use `R.spring(R.springConfigs.*)` instead of inline objects
- [x] **SPR-03**: All inline spring configs in `button.js`, `modal.js`, `panel.js`, `scene-helpers.js` replaced with `R.springConfigs.*` references
- [x] **SPR-04**: New spring configs can be added without modifying `R.spring` — registry is open for extension

### Renderer Primitive Hardening

- [x] **REND-07**: `R.strokeRoundRect` — add `lineWidth` parameter validation (clamp to ≥0.5)
- [x] **REND-08**: `R.doubleBezel` — add `opts.insetHighlight` support for custom inner highlight color; add null-check for `coreW/coreH ≤ 0`
- [x] **REND-09**: `R.easePremium` — add `R.easePremiumInv(t)` inverse function for progress-to-time mapping
- [x] **REND-10**: `R.spring` — add `R.spring.step(springState, dt)` alias for cleaner caller code
- [x] **REND-11**: `R.reducedMotion()` — add `R.reducedMotion.watch(cb)` for reactive listeners (opt-in)
- [x] **REND-12**: Semantic tokens — add `focus`, `success`, `warning`, `danger` tokens to `R.colors` for consistent state colors

### Test Coverage Requirements

- [x] **TEST-01**: `tests/component_factory.test.js` — 39 tests verifying `UI.Component` + mixins
- [x] **TEST-02**: `tests/spring_registry.test.js` — 9 tests verifying `R.springConfigs` registry
- [x] **TEST-03**: `tests/renderer_extended.test.js` — 22 tests covering REND-07..12
- [x] **TEST-04**: All new tests pass `node --test tests/*.test.js` (actual: 579 pass, 0 fail — target was ≥520)

### Out of Scope for v10.0

| Item | Reason |
|------|--------|
| Full Tailwind/DOM migration | Never — immediate-mode Canvas is the runtime contract |
| Scene lifecycle overhaul (enter/leave/update/render) | Scene-specific logic varies too much; defer to v11 |
| Gameplay/system overhaul | Out of scope — this milestone is shared-UI foundations only |
| Build step / bundler | Never — zero-build is a core constraint |
