### Phase 55: Element Burst Particles
**Goal:** Add pre-allocated element-colored particle burst on combat impact; `R.elementBurst` API; `R.colors.elements` tokens.
**Depends on:** Phase 54
**Requirements:** DMG-06, DMG-07
**Plan:** 55-01 — Element Burst Particles (15 tests, renderer.js + combatFx.js + combat.js + combatScene.js + test file)

**Goal:** Wire `R.elementBurst` at both combat hit sites (player→enemy, enemy→hero); dedicated test file; full suite green.
**Depends on:** Phase 54, Phase 55
**Requirements:** DMG-08, DMG-09, DMG-10
**Plan:** 56-01 — Combat Integration + Tests (11 tests, combatScene.js + test file)
