# Milestone v4.0: Deep Companions & Living Zones

**Status:** ✅ SHIPPED 2026-10-09
**Phases:** 21-29
**Total Plans:** 26

## Overview

Existing zones feel deeper through companion relationships — heroes and spirit beasts grow with the player and reshape how familiar regions play. No new realm geography; no backend/multiplayer; no framework/renderer migration; companion state extends existing heroes/beasts/save contracts (no parallel stores).

## Boundaries

- No new realm geography: deepen existing zones only (new landmarks, encounters, echoes within current zone IDs).
- No online backend, multiplayer, cloud sync, or server authority.
- No framework, renderer, bundler, or ES-module migration; vanilla JS, Canvas 2D, script order, and global/immediate-mode conventions stand.
- Companion systems are presentation + authoritative-state extensions of existing heroes, beasts, and save/world-state contracts — no parallel stores.
- Browser-evidence debt (v2.0 + v3.0 matrices) was scheduled early in v4.0 (Phase 21): headless harness green, live journey matrix deferred as accepted residual (v2.0/v3.0 precedent).

## Milestone Summary

**Decisions:**
- Single-authority BondSystem in `src/systems/bond.js` (never-throw, no R/UI dependency) owns affinity, arcs, combat bonuses, combos, and gifts; BeastBond lives in the same file as a separate global.
- Combat authority preserved via battle-clone-only application; linger consumed on win AND loss.
- COMMIT-ALL-FIVE readability verdict (Phase 25): all five heroes ship signature combos.
- Gifts route through canonical Economy + BondSystem; Use/Equip untouched; loot-only sourcing.
- Zero new zone IDs; bond references computed at read time (no persistence change).

**Issues:** Live-browser journey matrix unexecuted (EVD-01 F1–F5/W1–W5 rows pending; Phase 21 headless harness green). Accepted residual per v2.0/v3.0 precedent.

**Tech debt:** Browser/device evidence debt now spans v2.0 + v3.0 + v4.0 feature walkthroughs (affinity meter, bond scenes, combat log/Toast, duo button, feed/train taps, aura lines, variant tease, gift picker). Six untracked `.planning/debug/*.md` scratch notes remain uncommitted working notes.
