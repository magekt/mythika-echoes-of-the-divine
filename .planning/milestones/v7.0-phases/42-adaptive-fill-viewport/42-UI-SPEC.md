## Viewport Tier Contracts (core of this phase)

Authoritative presentation rules per form factor. Breakpoint numbers follow current web best practice (researcher directive from discuss — confirm against baseline device set, do not invent custom breaks).

| Tier | Canvas behavior | Frame & chrome |
|------|-----------------|----------------|
| Mobile portrait (~390×844) | Logical width 400, adaptive height (≈865); fills screen edge-to-edge | Backgrounds + full decor bleed to edges; interactive chrome inside safe-area insets; extra vertical space distributed as breathing room between sections |
| Mobile landscape (~844×390) | Adaptive width (≈865), height 400; fills screen | Compact chrome (smaller headers/HUD) so content fits; symmetric cutout padding both sides; toast lane MUST be viewport-aware (today hardcoded off-screen — Phase 32 D-04) |
| Tablet (own tier incl. portrait) | Roomier same layout: same arrangement, larger spacing/panels/targets | Tablet spacing scale; foldables near-square fall under tablet tier, no special case |
| Desktop | Legacy 400×720 card preserved; scale capped at 1, centered | Gold-bordered frame KEPT (premium identity); fluid stage growth with window up to cap; ultra-wide keeps filling fluidly (no backdrop cap); snap refit on resize release |
| Narrow floors | Minimum stage width ~360px (slide-over/popups letterbox, never crush) | — |
| Keyboard open | Hold layout (keyboard overlays; no refit jump) | Auth input overlays must stay aligned in container space |
| Browser zoom | Tiers follow effective CSS pixels | — |

**Universal rules:** backgrounds + vignette + hairlines + zone tints stretch to the real viewport (base wash AND decor); interactive chrome always clears rounded corners and notches by default; `transform-origin` unified (JS and CSS media query must agree); DPR backing re-initialized per refit (cap 3), text stays crisp.

## Spacing Scale

Logical px in the adaptive viewport (backing ×dpr). Multiples of 4 unless noted.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Minimum adjacent-button gap (LAY-04 hard floor); compact spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks (primary action height band) |
| safe | `env(safe-area-inset-*)` | Notch/home-indicator/corner clearance, subtracted ONCE in JS sizing |

Radius: `R.radius` xs=3 (chips/ticks), s=5, m=8, l=10. No raw radii in new code.

Exceptions: safe-area values (device-driven); DPR backing pixels.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | `R.fonts.md` | regular | 1.4 |
| Label | `R.fonts.sm` | regular | 1.4 |
| Heading | `R.fonts.lg` | semibold | 1.25 |
| Display | `R.fonts.display` (24) / `displaySm` (18) | serif | 1.2 |

No hard-coded canvas font strings; all type through `R.fonts` (respects fontScale). Text must never overflow its panel at any tier (LAY shared criterion).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0a0a1a` dark navy | Page/body background, scene wash base |
| Secondary (30%) | `#15152a` surface navy | Game container, cards, panels |
| Accent (10%) | `#e8a030` gold | Borders, primary CTAs, headings, currency icons, active states |
| Destructive | `R.colors.red` | Destructive actions only |

Accent reserved for: container/frame borders, primary action buttons, title/heading text, currency + lock-icon gold semantics, toast achievement accents — never body text or backgrounds. No raw hex in new scene/component code; `R.colors` tokens only (static data color values grandfathered).
