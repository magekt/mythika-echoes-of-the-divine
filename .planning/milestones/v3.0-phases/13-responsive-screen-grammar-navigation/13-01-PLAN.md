| Boundary | Description |
|---|---|
| viewport/browser → layout | Browser dimensions and safe-area environment values are untrusted inputs to scaling and geometry. |
| Canvas input → logical controls | Pointer/touch coordinates cross into game action hit-testing. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-13-01 | Tampering | viewport/layout math | mitigate | Clamp scale and all generated rectangles to finite logical bounds; test zero/very-small viewport values. |
| T-13-02 | Tampering | Canvas hit-testing | mitigate | Convert pointer coordinates through the displayed Canvas rect into `G.W/G.H` logical coordinates and regression-test scaled profiles. |
| T-13-03 | Denial of service | responsive resize handlers | mitigate | Keep one idempotent fit path and avoid per-frame listeners or allocations. |
| T-13-04 | Information disclosure | diagnostics/state labels | accept | Phase 13 adds no telemetry or sensitive data output; diagnostics remain Phase 20 scope. |
</threat_model>
