<interfaces>
From Plan 01 (existing):
```javascript
ZONE_VARIANTS // [{ id, zones:[zoneId], bondReq:{hero,affinityMin}|{beast,heartMin}, baseId, ... }]
ENCOUNTERS // includes the 12 lz_ ids
encounterAvailable(enc, ctx) // bondReq-aware
```

LivingZones API (new, all never-throw):
```javascript
LivingZones.variantsFor(zoneId) // ZONE_VARIANTS filtered by zone, [] unknown
LivingZones.eligibleIn(zoneId) // unseen + encounterAvailable-true variants, highest threshold first
LivingZones.resolveFor(zoneId) // first of eligibleIn() or null
LivingZones.teaseFor(zoneId) // string|null: null when no locked unseen variants remain or zone unknown; else "Deeper bonds with {Name} may open more in these lands…" naming the nearest-locked companion (lowest unmet threshold)
LivingZones.companionFor(zoneId) // { kind:'hero'|'beast', id, name, affinity|heart, oath:boolean }|null — highest-bond companion among the zone's variant heroes/beasts; oath true when bond_<hero>_oath flag set (heroes) or heart>=2 (beasts); null when nothing recruited/bonded
LivingZones.landmarkBondNote(zoneId) // string|null — "The land remembers {Name}, oath-bound companion." (oath) or "{Name}'s bond lingers here." (highest non-oath with value>0); null when companionFor null
LivingZones.echoWitness(regionId) // string|null — " — witnessed by {Name}, oath-bound" appended to echo desc when an oath companion exists for the region-as-zone; null otherwise
```

zoneExploration hook (in update(), after narrId roll): if narrId is a
standard (non-lz_) encounter id and LivingZones present, call
LivingZones.teaseFor(zoneId); if a string returns, show via Notify.show (or
UI.Feedback toast) guarded by typeof checks. Variant (lz_) rolls show no
tease. One toast per roll max; never blocks the gScene transition.
