- Display: hearts as '♥'.repeat(heart) + '♡'.repeat(3-heart) text via R.text
  with R.colors.gold / R.colors.textDim (semantic tokens only).

- Scene never writes G.state.gold/inventory/prana directly; all mutations go
  through BeastBond (which owns the Economy calls).
