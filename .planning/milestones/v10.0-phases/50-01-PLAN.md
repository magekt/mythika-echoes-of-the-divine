  <name>task 1: create src/ui/component.js with base factory and 5 mixins</name>
  <files>src/ui/component.js</files>
  <action>
Create `src/ui/component.js` with the following structure:

1. **UI.Component(x, y, w, h, opts)** - Base factory per COMP-01:
   - Returns object with: `x, y, w, h, render: noop, update: noop, contains: defaultRectContains, onClick: null, data: null`
   - Merges `opts` into returned object (shallow merge)
   - `defaultRectContains(px, py)` checks `px >= x && px <= x+w && py >= y && py <= y+h`
   - No per-frame allocation — all state allocated here

2. **UI.mixinRender(comp, drawFn)** - Per COMP-02:
   - Adds `render(ctx)` method that calls `drawFn(ctx, comp)`
   - Returns the component for chaining
   - Does NOT override existing `render` if already present (allows composition order)

3. **UI.mixinUpdate(comp)** - Per COMP-03:
   - Adds `update(dt)` method that calls `comp._updateHook?.(dt)`
   - Returns the component for chaining

4. **UI.mixinSpring(comp, config)** - Per COMP-04:
   - Adds `_springState = { value: config.target || 1, velocity: 0 }`
   - Adds `_springStep = R.spring(config)` — step function created ONCE at mixin time
   - Adds/extends `update(dt)` to advance spring: `const s = comp._springStep(comp._springState.value, comp._springState.velocity, dt); comp._springState.value = s.value; comp._springState.velocity = s.velocity;`
   - Stores result in `comp._springValue` for easy access
   - If component already has `update`, wraps it (calls original then spring step)
   - Returns the component for chaining

5. **UI.mixinEase(comp)** - Per COMP-05:
   - Adds `easedValue(t)` method that returns `R.easePremium(t)`
   - Returns the component for chaining

6. **UI.mixinContains(comp)** - Per COMP-06 (listed as COMP-06 in requirements):
   - Adds `contains(px, py)` using `R.radius.s` as hit-testing padding
   - Logic: `px >= comp.x - R.radius.s && px <= comp.x + comp.w + R.radius.s && py >= comp.y - R.radius.s && py <= comp.y + comp.h + R.radius.s`
   - Returns the component for chaining

All mixins must be pure functions that mutate and return the component. Zero per-frame allocation — all closures and state allocated at mixin application time (construction).
  </action>
