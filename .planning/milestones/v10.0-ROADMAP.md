## Phase Details

### Phase 50: UI Component Factory Foundation
**Goal:** Establish `UI.Component` base factory + 5 mixins (`mixinRender`, `mixinUpdate`, `mixinSpring`, `mixinEase`, `mixinContains`); refactor `UI.Button`, `UI.Panel`, `UI.Modal` to compose from base + mixins; zero per-frame allocation in any component.
**Depends on:** Nothing (first phase of v10.0)
**Requirements:** COMP-01, COMP-02, COMP-03, COMP-04, COMP-05, COMP-06, COMP-07
**Plan:** 50-01 — UI Component Factory + Mixins (39 tests, 5 files modified, 2 files created)

### Phase 51: Spring Config Registry
**Goal:** Create `R.springConfigs` registry with named spring configurations; replace all inline spring config objects in UI components and scenes with registry references.
**Depends on:** Phase 50 (needs `R.spring` from Phase 46)
**Requirements:** SPR-01, SPR-02, SPR-03, SPR-04
**Plan:** 51-01 — Spring Config Registry (9 tests, 2 files modified, 1 file created)

### Phase 52: Renderer Primitive Hardening
**Goal:** Harden `R.strokeRoundRect`, `R.doubleBezel`, `R.easePremiumInv`, `R.spring.step`, `R.reducedMotion.watch`; add 4 semantic color tokens; extend test coverage.
**Depends on:** Phase 46, Phase 50
**Requirements:** REND-07, REND-08, REND-09, REND-10, REND-11, REND-12
**Plan:** 52-01 — Renderer Primitive Hardening (22 tests, 1 file modified, 1 file created)

### Phase 53: Component Factory Migration + Test Suite
**Goal:** Migrate all remaining UI components to `UI.Component` + mixins pattern; ensure all spring configs use registry; full test suite green.
**Depends on:** Phase 50, Phase 51
**Requirements:** TEST-01, TEST-02, TEST-03, TEST-04
**Plan:** 53-01 — Component Factory Migration (580 total tests passing, 11 files modified, 6 tests updated)
