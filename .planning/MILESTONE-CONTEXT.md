# Milestone 2: Living Map & World State

## Vision
Transform the static Travel Map into a living, dynamic world that responds to the player's journey. Visual landmarks, region control, dynamic world events, and environmental storytelling that makes the world feel alive.

## What Ships
- Visual map with distinct region representations (not just list of zones)
- Landmark system: discoverable points of interest on the map
- Dynamic world state: zones change appearance/control based on player progress
- Region influence: player actions affect zone states
- Environmental storytelling: map reflects narrative choices
- World event system: periodic events visible on the map

## Constraints
- Preserve Canvas architecture
- No new zones (use existing zones + landmarks)
- No backend requirements (all local state)
- Mobile-first touch interaction
- Performance: map must render smoothly on mid-range phones

## Success Criteria
- Map feels alive, not static
- Player can see their impact on the world
- Touch interaction is smooth and intuitive
- World state persists across sessions
