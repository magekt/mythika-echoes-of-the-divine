# Quick Start Guide

Start playing **Mythika: Echoes of the Divine** in under 2 minutes.

## Launch the Game

1. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge)
2. Or serve locally: `npx serve .` then open `http://localhost:3000`

No build step, no dependencies to install — the game runs directly in the browser.

## First-Time Setup (30 seconds)

### 1. Title Screen
- **New Game** — Start a fresh adventure
- **Continue** — Load existing save (appears if you've played before)

### 2. Choose Your Path
Select a class that defines your starting bonuses:
- **Warrior** — Combat-focused, higher damage
- **Sage** — Spirit-focused, faster cultivation
- **Rogue** — Speed-focused, higher criticals

### 3. Name Your Hero
Enter your character name and allocate 10 stat points across:
- **Strength** — Physical damage
- **Agility** — Speed and dodge
- **Spirit** — Cultivation speed
- **Vitality** — Health pool

### 4. Select Starting Elite
Choose your first elite hero to lead your party.

## Your First 5 Minutes

### The Ashram (Home Base)
After character creation, you arrive at your **Ashram** — the central hub for all activities:

- **Map** — Travel to zones for combat and exploration
- **Party** — Manage heroes, equipment, and formations
- **Shop** — Buy and sell gear at the Bazaar
- **Rest** — Recover health between battles
- **More** — Settings, achievements, and other features

### Enter Combat
1. Tap **Map** from the Ashram
2. Select **Dandaka Forest** (first zone)
3. Choose **Explore** to enter turn-based combat

### Combat Basics
- **Tap a skill** to attack the selected enemy
- **Tap a hero** to select them for actions
- **Tap an enemy** to target them
- **Tap Auto** to let AI handle the battle

Victory grants gold, experience, and equipment.

### Check Your Progress
- **Level up** heroes in the Party screen
- **Equip** new gear found in battle
- **Advance cultivation** in the Ashram to unlock new abilities

## Core Game Loops

### Combat Loop
Travel → Fight → Loot → Return to Ashram → Upgrade → Repeat

### Progression Loop
Fight battles → Gain XP → Level heroes → Break through cultivation realms → Unlock new zones

### Idle Progression
The game continues while you're away:
- Heroes gain experience
- Resources accumulate
- Cultivation advances

## Save System

- **Auto-saves** every 60 seconds during gameplay
- **Manual save** available in Settings
- **Offline progress** calculated on return
- **Cloud saves** available via Firebase Auth (optional)

## Installation (Optional)

### Install as PWA (Progressive Web App)
- **Mobile Safari**: Tap Share → Add to Home Screen
- **Chrome Desktop**: Click install icon in address bar
- **Firefox**: Bookmark and enable offline mode

Benefits: offline play, faster loading, no browser UI.

## Tips for New Players

1. **Start with Dandaka Forest** — lowest difficulty, good for learning combat
2. **Allocate starting points evenly** — balanced stats help early progression
3. **Check the Party screen after each level** — new abilities unlock automatically
4. **Sell unused equipment** at the Bazaar for gold
5. **Return to the Ashram** to save before closing the browser
